# Programação Orientada a Objetos em Java

Este repositório foi criado para apoiar a disciplina de Introdução à Programação Orientada a Objetos, com foco na linguagem Java. Sua finalidade é reunir exemplos de código, exercícios e resoluções que ajudam no aprendizado dos conceitos fundamentais da programação orientada a objetos.

## Objetivo da disciplina

- Compreender os pilares da programação orientada a objetos;
- Aprender a linguagem Java na prática;
- Desenvolver soluções organizadas e reutilizáveis;
- Aplicar conceitos de modelagem em problemas reais;
- Praticar a resolução de exercícios de forma gradual.

## Conceitos abordados

- Classes e objetos;
- Atributos e métodos;
- Construtores;
- Encapsulamento;
- Herança;
- Polimorfismo;
- Sobrecarga e sobrescrita;
- Abstração;
- Interfaces;
- Coleções e estruturas básicas.

## Conteúdo do repositório

O material disponível neste repositório pode incluir:

- Exemplos de código em Java;
- Exercícios propostos;
- Soluções comentadas e resolvidas;
- Práticas de programação e organização de código;
- Arquivos de apoio para estudo e revisão.

## Como utilizar

1. Clone o repositório em sua máquina;
2. Abra o projeto em uma IDE Java, como IntelliJ IDEA, Eclipse ou VS Code;
3. Estude os exemplos e entenda os conceitos aplicados;
4. Tente resolver os exercícios antes de consultar as respostas;
5. Compare suas soluções com as resoluções disponíveis para aprender melhor.

## Dicas de estudo

- Pratique com frequência;
- Entenda a lógica antes de copiar o código;
- Teste os exemplos em Java;
- Revise os conceitos básicos sempre que necessário;
- Busque relacionar a teoria com exercícios práticos.

## Observação

Este repositório tem caráter acadêmico e educativo, sendo uma ferramenta complementar para o aprendizado de programação orientada a objetos com Java.
